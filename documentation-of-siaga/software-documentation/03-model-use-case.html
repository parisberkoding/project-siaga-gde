Relasi «include» dan «extend»

Relasi «include» dipakai untuk perilaku yang selalu dijalankan oleh use case sumber sehingga layak difaktorkan menjadi satu use case tersendiri. Relasi «extend» dipakai untuk perilaku opsional atau kondisional yang memperluas use case dasar pada titik tertentu.

Tipe RelasiUse Case SumberUse Case TargetAlasan / Domain rule

includeUC-BBM-02 Meninjau & Menyetujui PermohonanUC-SYS-02 Memeriksa Hak Akses (RBAC)Rute approval berada pada grup permission:bbm.approve; admin tanpa izin tidak dapat memproses.

Tiga modul berikut dipilih karena memuat aturan bisnis paling padat dan menjadi tulang punggung operasional harian Divisi General Affairs.

Ketertelusuran ke kebutuhan PRD

Setiap use case harus dapat ditelusuri balik ke kebutuhan fungsional pada PRD.md. Tabel berikut memetakan prefiks use case ke bagian PRD yang menjadi sumbernya, sehingga perubahan kebutuhan dapat langsung ditelusuri ke use case, spesifikasi, dan pengujiannya.
